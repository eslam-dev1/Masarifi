# Masarifi

تطبيق أندرويد لتسجيل المصروفات اليومية والشهرية، بواجهة عربية وإنجليزية، وحفظ محلي للبيانات عبر Room.

## المزايا الحالية
- إضافة المصروفات وتعديلها وحذفها.
- إجمالي المصروفات اليومي والشهري، والتجميع حسب التصنيف، ومخطط آخر 7 أيام.
- ميزانية شهرية محفوظة محليًا، مع عرض المتبقي والتنبيه بصريًا عند تجاوزها.
- تبديل العربية/الإنجليزية واتجاه الواجهة، مع حفظ الاختيار.
- وضع فاتح وداكن مع حفظ الإعداد.
- قاعدة Room مع ترحيل آمن من إصدار قاعدة البيانات 1 إلى 2.

## التشغيل
افتح المشروع في Android Studio، نفّذ Gradle Sync، ثم شغّل تطبيق `app`. البيانات محلية على الجهاز ولا تتطلب اتصالًا بالإنترنت.
